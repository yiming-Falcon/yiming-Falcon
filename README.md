## Featured Project

### [YM PM Skills](https://github.com/yiming-Falcon/ym-pm-skills)

Three Agent Skills for the early and delivery stages of AI projects:

- `ym-pmintake`: clarify the business problem, first MVP, risks, and acceptance criteria.
- `ym-pmclean`: organize project files, truth sources, history, and handoff.
- `ym-pmsafety`: review data, access, secrets, deployment, and automation by risk level.

The first public release includes six blind evaluation cases, 24 fixed assertions, real-project validation, and clean installation tests.
